# TailScaleKeen

Веб-панель управления **Tailscale / Headscale для Keenetic и Netcraze с Entware ARM64**. Интерфейс на русском языке, светлая и тёмная темы, отдельная учётная запись. Работает локально, без облачного сервиса проекта, Node.js и внешних CDN.

**[Установка и настройка → README.ru.md](README.ru.md)** · [Релизы](https://github.com/Zhanchuraev/TailScaleKeen/releases) · [Изменения](CHANGELOG.md) · [Безопасность](SECURITY.md)

## Установка одной командой

Выполните в **SSH Entware от root**, когда Entware `aarch64-k3.10` уже установлен:

```sh
(set -e; opkg update; opkg install curl ca-bundle; mkdir -p /opt/tmp; f="$(mktemp /opt/tmp/tailscalekeen.XXXXXX)"; trap 'rm -f "$f"' EXIT; curl -fLsS --connect-timeout 15 --max-time 90 https://raw.githubusercontent.com/Zhanchuraev/TailScaleKeen/main/install.sh -o "$f"; sh "$f")
```

Откройте `http://<локальный-IP-роутера>:8092/`. При первом входе создайте **свои** логин и пароль, затем повторите пароль. Предустановленных учётных данных и сервера Headscale нет. Минимальная длина пароля — 6 символов; используйте длинный уникальный пароль.

Установщик добавляет необходимые зависимости и последний стабильный официальный клиент Tailscale ARM64, проверяет SHA256. Прошивку и существующий Entware не переустанавливает. Для уже работающего клиента поддерживается описанная в инструкции компоновка `/opt/bin` + `S06tailscaled`; произвольные сторонние сборки требуют отдельной проверки.

## Что умеет

- Подключение к официальному Tailscale или **своему Headscale**: браузерный вход или ключ регистрации.
- Создание подключения `OpkgTun` в панели Keenetic с предварительным просмотром команд.
- Выбор внешнего Exit node и объявление роутера своим Exit node.
- Выбор выхода для клиентов собственного Exit node: система, доступное WAN, политика Keenetic/VPN, существующий XKeen.
- Объявление подсетей, принятие маршрутов, DNS, SNAT и фильтрация соединений.
- Устройства, онлайн-статус, соединение direct/DERP, трафик, карточки, заметки и ссылки на веб-интерфейсы.
- Диагностика, журналы, резервные копии **параметров** клиента.
- Отдельные обновления **клиента** и **самой панели из GitHub**; проверка архива, сохранение настроек и откат при неуспешном запуске панели.
- Смена учётной записи, сброс через SSH, безопасная проверка нового порта до сохранения.

Одновременно используется одна сеть Tailscale/Headscale. Одобрение маршрутов и Exit node выполняется администратором вашей сети. Возможности своего контроллера не подменяются этой панелью.

## Удаление одной командой

```sh
tailscalekeen uninstall --purge
```

Удаляются панель, клиент, его локальные ключи, настройки, журналы и поддерживаемая интеграция Tailscale. Общие пакеты Python/curl/Entware и другие приложения сохраняются. Устройство в административной консоли Tailscale/Headscale удалите отдельно. Просмотр списка перед удалением: `tailscalekeen uninstall --dry-run`.

## Обновление

В панели: **Клиент и панель → Обновить WebUI TailScaleKeen → Применить**. После перезапуска войдите снова. Кнопка «Обновить клиент Tailscale» отдельно проверяет и обновляет официальный клиент.

Через SSH: `tailscalekeen check-update` и `tailscalekeen update`.

## Совместимость и разработка

Целевая среда: **Entware aarch64-k3.10, Python 3.11+, KeeneticOS/NetcrazeOS с OpkgTun и CLI `ndmc`**. ARM32/MIPS не поддерживаются этим установщиком. Публичный выпуск проверяется на ARM64-роутере и изолированных файловых системах; это не заявление о проверке всех моделей и сторонних установок.

Для 1.0.2 предусмотрены 98 тестов, включая проверки свободного места и запрет самообновления из тестовых каталогов. Полный цикл на Entware ARM64 проверяется в отдельном каталоге: официальный ARM64-клиент, первый аккаунт, запуск HTTP, обновление панели, намеренно вызванный отказ с откатом, сохранение аккаунта и полное удаление. Сетевая интеграция новой установки проверяется сценарными тестами; заводская установка и физические LAN-клиенты всех моделей отдельно не проверялись.

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_public.py
python3 scripts/build_release.py
```
