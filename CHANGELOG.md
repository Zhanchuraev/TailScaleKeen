# Изменения

## 1.1.2

- В списке клиентов IPv6 показан второй строкой под IPv4 меньшим приглушённым шрифтом, по образцу Keenetic.
- У каждого адреса своя кнопка копирования. Клиенты с единственным IPv4 или IPv6 показываются без пустой строки.
- В инструкции пояснено отличие штатного индикатора OpkgTun от состояния клиента Tailscale.

## 1.1.1

- Раздел «Устройства» переименован в «Клиенты»; у группы «Локальная сеть» значок Wi-Fi по образцу Keenetic.
- Рядом с отображаемым IP добавлена компактная кнопка копирования. Поддерживаются IPv4/IPv6, клавиатура и обычный HTTP без Clipboard API.
- MAC-адреса удалённых клиентов не выводятся: Tailscale не передаёт их в статусе узлов. Локальные LAN MAC не подставляются вместо них.

## 1.1.0

- Диагностика состояния компонентов, прав доступа и ресурсов; скачиваемый отчёт по строгому списку полей без адресов, имён, сервера, заметок, журналов и ключей.
- Проверка туннеля WireGuard через TSMP для известных узлов сети.
- Анонимные сессии больше не вытесняют авторизованного администратора; устаревшие адреса не накапливаются в ограничителе попыток входа.
- Отмена и истечение предварительного просмотра удаляют ключ регистрации из ожидающего действия; число планов ограничено, записи сериализованы.
- Настройки повторно проверяются после получения блокировки непосредственно перед выполнением операции.
- Ошибки записи/очистки заданий и отказ запуска потока освобождают блокировку следующих операций.
- Закрытые права журнала устанавливаются с момента создания; запись и ротация журнала сериализованы.
- Условная загрузка статики ETag/304; API остаётся no-store. Ограничено ожидание ответа браузером и устранены повторные параллельные входы при истечении сессии.


## 1.0.2

- Вверху раздела «Клиент и панель» постоянно видны две отдельные кнопки: «Обновить WebUI TailScaleKeen» и «Обновить клиент Tailscale».
- Каждая кнопка проверяет свой компонент и показывает подтверждение перед установкой; скрытых кнопок обновления больше нет.
- Проверка актуальности клиента учитывает версию CLI, файл daemon и версию работающего daemon.

## 1.0.1

- Проверка свободного места до замены панели и установки клиента: 64 МБ для панели, 240 МБ для нового клиента.
- При проверке установленного клиента учитываются версии обоих файлов: `tailscale` и `tailscaled`. Несовпадающая пара восстанавливается проверенным обновлением.
- В установщике и самообновлении учитывается реальный путь `/opt`, в том числе размещение на символической ссылке.
- Дополнительные проверки, что при нехватке места установка останавливается до загрузки бинарного архива и записи кода.

## 1.0.0

Первый публичный выпуск TailScaleKeen для Entware ARM64.

- Подключение Tailscale/Headscale, устройства, Exit node, маршруты, DNS и OpkgTun.
- Для чистых установок: выбор свободного TUN, собственная интеграция NDM/firewall с проверкой конфликтов и защитой штатной LAN. Существующие обработчики сохраняются.
- Выбор выхода собственного Exit node через WAN/политику VPN/совместимый XKeen.
- Русский интерфейс с двумя темами, карточками устройств, заметками и трафиком КБ/МБ/ГБ.
- Независимый аккаунт первого входа; сброс логина и пароля через SSH, проверка нового порта.
- Установка и полное локальное удаление одной командой.
- Обновление панели из фиксированного GitHub Releases с SHA256, манифестом, проверкой запуска и откатом.
- Официальный стабильный Tailscale ARM64 обновляется отдельно, с сохранением идентичности.
- Ограничение истории заданий и правильная сортировка по времени.
- Атомарная запись JSON с закрытыми правами с момента создания временного файла.
- В публичный дистрибутив включаются только разрешённые файлы; примеры и тесты используют вымышленные настройки.
